METHODOLOGY

How It Works

Piscipedia uses the active historical score/rank dataset. It finds nearby historical marks and estimates the rank using interpolation when observations bracket the submitted score; otherwise it uses the closest available observation.

The result includes a range and confidence level. Category and domicile fields are collected and retained, but this initial dataset does not contain category/domicile columns, so the engine does not invent category or domicile adjustments.

Data integrity

User predictions are stored separately from historical records. A user's predicted rank is never treated as an actual rank. Administrators can later verify actual ranks and use verified records for future modelling.
